# 六壬推算 - 网页版部署指南

## 🎯 一键部署方案（推荐）

### 方案1：Vercel（最快，30秒完成）

1. 访问 https://vercel.com
2. 使用 GitHub 账号登录
3. 点击 "Add New..." → "Project"
4. 选择 "Import Third-Party Git Repository"
5. 粘贴本仓库地址，或直接拖拽 `liuren-web` 文件夹到页面
6. 点击 "Deploy"

**免费地址**: `https://your-project.vercel.app`

### 方案2：Netlify（最简单）

1. 访问 https://netlify.com
2. 点击 "Add new site" → "Deploy manually"
3. 拖拽 `liuren-web` 文件夹
4. 获得永久链接

### 方案3：GitHub Pages（永久免费）

1. 创建 GitHub 仓库
2. 上传 `index.html` 文件
3. 进入 Settings → Pages
4. Source 选择 "Deploy from a branch" → main
5. 获得 `https://你的用户名.github.io/仓库名`

## 🌐 自定义域名（可选）

在 Vercel/Netlify 中：
1. 进入项目设置 → Domains
2. 添加你的域名（如 liuren.com）
3. 按提示添加 DNS 记录
